# UniHelper на Cloudflare

Приложение и утренняя сводка в одном проекте Cloudflare Workers. Всё на бесплатном тарифе:
- сама страница приложения отдаётся без лимита;
- до 100 000 запросов к серверу в сутки;
- рассылка раз в час по расписанию;
- данные хранятся в KV.

## Что где лежит

| Файл | Что это |
|---|---|
| `public/index.html` | само приложение (дальше обновлять именно его) |
| `src/worker.js` | сервер: `/api/sync` и утренняя рассылка |
| `src/telegram.js` | проверка подписи Telegram и отправка сообщений |
| `src/digest.js` | текст утренней сводки |
| `wrangler.jsonc` | настройки Cloudflare: расписание, хранилище |

## Перенос (один раз, ~15 минут)

1. **GitHub.** Создайте новый репозиторий, например `uni-helper-cf`. Загрузите в него содержимое архива так, чтобы `wrangler.jsonc`, `package.json` и папки `src`, `public` лежали в корне репозитория, а не внутри ещё одной папки.
2. **Cloudflare.** Зарегистрируйтесь на dash.cloudflare.com (бесплатно, карта не нужна) и откройте **Workers & Pages → Create → Import a repository**. Подключите GitHub и выберите репозиторий.
   - Build command — оставьте пустым.
   - Deploy command — `npx wrangler deploy` (стоит по умолчанию).
   - Нажмите **Deploy**.
3. **Токен бота.** Откройте созданный Worker → **Settings → Variables and Secrets → Add**.
   - Тип: **Secret**.
   - Имя: `BOT_TOKEN`.
   - Значение: токен из @BotFather.
   - Сохраните (**Deploy**).
4. **Адрес.** Адрес приложения указан на странице Worker: `https://uni-helper.<ваше-имя>.workers.dev`. Вставьте его в @BotFather в трёх местах:
   - `/myapps` → бот → **Edit Web App URL**;
   - `/mybots` → бот → **Bot Settings → Menu Button**;
   - `/mybots` → бот → **Bot Settings → Configure Mini App**.
5. **Проверка.** Откройте приложение кнопкой в боте, нажмите колокольчик и выберите **«Прислать сводку сейчас для проверки»**. Сводка должна прийти в чат.

## Данные

Предметы, расписание и заметки вернутся сами: при первом открытии на новом адресе приложение подтянет их из резервной копии в Telegram. Если копия почему-то пустая, расписание можно заново загрузить из того же PDF.

## Как обновлять

Меняйте файлы в репозитории на GitHub, например `public/index.html`. Cloudflare пересоберёт и опубликует проект сам за минуту, без кредитов и лимитов на число обновлений.

## Если что-то пошло не так

- **Деплой упал с ошибкой про KV namespace / id.** Создайте хранилище вручную: **Storage & Databases → KV → Create**, имя `uni-users`, скопируйте его **ID**. В `wrangler.jsonc` замените `{ "binding": "USERS" }` на `{ "binding": "USERS", "id": "скопированный-id" }`.
- **«На сервере не задан BOT_TOKEN».** Шаг 3 не сохранён, или переменная создана с другим именем.
- **«Подпись Telegram не прошла проверку…».** Сообщение подскажет, от какого бота токен на сервере.
- **Логи сервера и утренней рассылки:** Worker → **Observability / Logs**.
